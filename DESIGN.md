# Design system
Professional light theme using UX4G 3.0.0 from npm. White, warm neutral, sage and pale blue surfaces; navy text and restrained burnt orange emphasis. Manrope display type and DM Sans body type. Editorial hierarchy, large whitespace, detailed product previews and structured architecture diagram. No invented performance evidence.

Components: UX4G button and tab foundations, custom semantic accessible controls, native disclosure elements. Source-backed product previews use explicit illustrative labels. Responsive layouts at 1100, 800 and 480 pixels. Reduced-motion support and visible keyboard focus.

User explicitly delegated visual decisions and requested a light theme. Source product content remains the factual input; marketing statements are not independently verified.
